# XURL — Short-URL Generator & Retriever

A URL-shortener service exposing REST endpoints to generate short links and resolve them back to the original URLs.

## Features
- Short-link generation and retrieval via REST
- Persistence-backed link storage

## Tech stack
Java · Spring Boot · REST

## Context
Built as part of [Crio.Do](https://www.crio.do/)'s project-based curriculum (2022–23) — one of a series of backend projects; see the full portfolio at [github.com/OmKumarBhardwaj](https://github.com/OmKumarBhardwaj).
